# PareCure storefront

A responsive, luxury-inspired skincare storefront built with vanilla HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser, or serve the repository root with any static web server.

## Current experience

- Responsive landing page and product collection
- Brand story and skincare ritual sections
- Mobile navigation
- Interactive shopping bag preview
- Newsletter form interaction placeholder

## Before accepting real orders

- Replace editorial placeholder photography with approved PareCure product photos.
- Confirm product descriptions, ingredients, usage directions, pricing and stock.
- Connect a secure checkout and payment provider, order management and delivery settings.
- Connect newsletter sign-ups to an email service and add the final privacy/returns/shipping policies.

The current shopping bag is a front-end preview only; it does not place orders or process payments.
