# PareCure storefront

A responsive skincare storefront built with React 19 and Vite.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally
Run `npm install`, then `npm run dev`.

## Production build
Run `npm run build`, then `npm run preview` to preview the production bundle.

## Current experience
- Responsive storefront with desktop and mobile layouts
- PareCure brand story and skincare ritual sections
- React-powered product collection and shopping bag preview
- Mobile navigation and newsletter interaction placeholder

## Before accepting real orders
- Replace editorial placeholder photography with approved PareCure product photos.
- Confirm product descriptions, ingredients, usage directions, pricing and stock.
- Connect secure checkout/payment, order management and delivery settings.
- Connect newsletter sign-ups to an email service and add final privacy, returns and shipping policies.

The shopping bag is a front-end preview only; it does not place orders or process payments.
