# PareCure logo assets

Place the approved PareCure logo files in this folder.

Suggested filenames:
- `parecure-logo.svg` — primary logo for headers and general use
- `parecure-logo.png` — transparent PNG fallback
- `parecure-icon.png` — square icon/favicon source

Use the SVG where possible for crisp rendering at all screen sizes. Reference files from the Vite app with URLs such as `/assets/logo/parecure-logo.svg`.
